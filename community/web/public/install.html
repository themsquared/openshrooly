USB installer

Flash the chamber from the browser

This is the same ESP Web Tools flow as openshrooly.com. Use Chrome or Edge on a computer. Hold BOOT if the port does not appear.

Loading the signed release manifest…

  1. Plug the chamber in over USB-C.
  2. Click Install and pick the USB serial port.
  3. After reboot, join OpenShrooly and open http://192.168.4.1/app/.

Release checksums can be signed. The site refuses an unsigned OTA file when signing is enabled. USB factory flash still works either way.
