Culinary Profile

Reishi

Reishi fruits at 23 C and 85% RH with moderate FAE and 12 h light. About 77 days from start to fruit. Antlers under high CO2, then consoles when FAE increases.

Ganoderma lucidum, Red reishi

Grow parameters

  1. Colonization 21 d, 88% RH, 27 C

  2. Antler / primordia 21 d, 90% RH, 24 C

    Low FAE keeps growth as antlers.

  3. Console formation 35 d, 85% RH, 23 C

    Increase FAE and light to flatten antlers into consoles.
