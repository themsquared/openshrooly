Culinary Profile

Button / Cremini

Button / Cremini fruits at 16 C and 88% RH with moderate FAE and 2 h light. About 36 days from start to fruit. Compost + casing species. Low light, cool fruiting, casing required.

Agaricus bisporus, Brown cremini

Grow parameters

  1. Spawn run 16 d, 88% RH, 24 C

    Colonize compost in the dark before casing.

  2. Casing / pinning 8 d, 92% RH, 17 C

    Apply a non-nutritive casing, then drop temp.

  3. Fruiting 12 d, 88% RH, 16 C
