Culinary Profile

Wine Cap

Wine Cap fruits at 17 C and 85% RH with moderate FAE and 12 h light. About 40 days from start to fruit. Best as an outdoor bed mushroom. Indoor profile is a climate approximation only.

Stropharia rugosoannulata, Garden giant

Grow parameters

  1. Colonization 21 d, 85% RH, 22 C

  2. Pinning 7 d, 90% RH, 18 C

  3. Fruiting 12 d, 85% RH, 17 C
