How to run a Lykyn with Shroom Labs firmware

Updated 2026-11-15

Shroom Labs runs a Lykyn with native firmware on the ESP32-C3, validated on a real unit. Back up the stock 4 MB flash first, flash the public image, and do not erase the flash. After that the box has a local dashboard, an optional cloud link, grow profiles, and Coach. This used to describe an outside-control plan that left the stock app in place. That is no longer the supported path.

Does Shroom Labs work with a Lykyn now?

Yes. Native firmware from the Shroom Labs Lykyn firmware repo runs on a real unit. The chambers table marks Lykyn as supported, the same status as a Shrooly chamber.

Once it is installed you can:

  • Open the local dashboard at the chamber's address. The stock ESPHome entity table is at /esp.
  • Link the box to a Shroom Labs account with the claim code it shows, or leave cloud off and stay on the LAN.
  • Start a culinary grow profile. Colonization on a Lykyn uses the phase name Colonization. A Shrooly chamber uses Colonizing for the same stage.
  • Use Grow Coach in Advisor or Autopilot mode. Turn Coach off before you set targets yourself.

Read Lykyn for mushrooms for the hardware, ranges, and stage names.

How do I flash a Lykyn safely?

Back up the full stock flash first. The stock image and Shroom Labs firmware share a 4 MB partition layout, so that backup can be written back. Do not run erase_flash: that can wipe factory data the backup is meant to keep.

  1. Read the flash guide in the firmware repo. Use a USB data cable. The ESP32-C3 has native USB-Serial/JTAG, and download mode is how you put the chip in flash mode.
  2. Save a complete 4 MB backup of the unit as it shipped, and keep that file somewhere you can find.
  3. Build or download the image from the public repo. The provisioning build has no Wi-Fi baked in. After it boots, the box opens a Lykyn-Setup network, and Improv over USB also works.
  4. Flash only the slots the guide names. If something goes wrong, write the backup back. USB is the way home.

This is not the USB installer for a Shrooly chamber. That page is for Shrooly chambers only.

What can the firmware actually do?

It reads the SHT3x for temperature and humidity, runs a local climate loop with no cloud required, and drives both PWM fans, the ultrasonic mister, and the 16 pixel grow ring.

  • Humidity targets: 30 to 95 percent relative humidity, in 0.5 steps.
  • Fans: 0 to 100 percent PWM on the inlet and outlet.
  • Stages: Fruiting, Pinning, Colonization, and Custom. Colonization lights stay off.
  • There is no heater or cooler. Over-temperature or over-humidity boosts the fans. If the sensor is lost for 60 seconds, the mister turns off and the fans keep some air moving.

Cloud is optional. A cloud failure does not change the local loop.

How is this different from a Shrooly chamber?

Both now run Shroom Labs firmware and can link to the same site, profiles, and Coach. The differences are the hardware and a few names and ranges.

What happened to the outside-control plan?

Before the unit arrived, this guide described talking to the official Lykyn app and cloud without flashing, and leaving the stock software on the box. That work was never the validated path. The Shroom Labs Lykyn adapter on GitHub is still public as notes, and credentials stay out of it.

If you do not want to flash, you can keep the official Lykyn app and copy numbers from a grow profile by hand. Automatic apply, the local Shroom Labs dashboard, and Coach need the native firmware.

FAQ

Does Shroom Labs work with a Lykyn now?

Yes. Native firmware runs on a real unit, with a local dashboard, an optional cloud link, grow profiles, and Coach.

How do I flash a Lykyn safely?

Back up the full stock flash first, then flash the public image. Do not erase the flash.

Will I lose the stock firmware?

Not if you keep a full 4 MB backup. The partition layout matches stock, so you can write that backup back.

Can I use Grow Coach on a Lykyn?

Yes. Advisor suggests targets, and Autopilot can queue them. Turn Coach off before you set targets yourself.

What happened to outside control?

That was the plan before the unit arrived. The supported path is now native firmware. The older adapter repo remains public as notes.
