Outside control for a Lykyn mushroom grow box

Updated 2026-11-13

Outside control means we talk to a Lykyn through the same Socket.IO protocol its cloud uses, and we leave the stock software on the box. Our unit is on the bench. The public lykyn-adapter has a stand-in, Black Oyster example profiles, and protocol notes. A live LAN push still needs a TLS cert the stock box trusts for lykyn.app, or a logged-in cloud session. This is not a reflash, which is how OpenShrooly runs a Shrooly chamber.

What does outside control mean?

Outside control is a way to read and set a chamber without replacing the software that shipped on it. The stock firmware stays. We speak the same language the official cloud already speaks.

For a Lykyn that means:

  • Stock software stays on the box. We do not flash it. We do not ask you to open it.
  • The box talks Socket.IO to lykyn.app. Our stand-in accepts updateDevice telemetry and pushes settings the firmware applies.
  • Credentials stay with you. Device ids and account tokens live in a local .env. Shroom Labs does not store them.
  • A dry run comes first. The CLI prints a plan by default and only writes when you add an apply flag on purpose.

Read Lykyn for mushrooms for the current status.

What did we record from the box on the bench?

Our Single-Tier MUSHROOM box is on firmware 0.17.0 (ESP32-C3). From a read-only dump and its serial log we recorded:

  1. Cloud protocol. Engine.IO v4 / Socket.IO on path /socket.io/ to lykyn.app over TLS.
  2. Telemetry. The box emits updateDevice with temperature, humidity, fans, humidifier, light, and current settings.
  3. Settings push. The cloud sends a settings object (as getDeviceInfo). The firmware applies any non-special event that carries that shape.
  4. Hardware. Sensirion SHT3x sensor, inlet and outlet fans, humidifier, addressable LED strip. GPIO map and clamps are in the lykyn-adapter docs.

Wi-Fi names, device ids, and tokens stay out of the public repo.

What is still untested?

A live LAN settings push against a stock box. The stand-in and its unit tests pass with a fake client. A real box verifies TLS certificates for the hostname lykyn.app, so a DNS override alone is not enough.

  • Whether a trusted TLS path on the LAN can complete the handshake.
  • Whether a logged-in Lykyn cloud session can drive the same settings from Shroom Labs.
  • How a Lykyn compares to a Shrooly chamber on the same block. That comparison is the planned grow log.

The chambers table marks it On bench, outside control in progress. The grow log marks it on bench with a Black Oyster bag. Neither says Supported until a real push lands.

How is this different from flashing a Shrooly chamber?

OpenShrooly replaces the stock software on a Shrooly chamber. You install it from Chrome or Edge with a USB-C cable in about 5 minutes. After that the chamber runs on your own Wi-Fi from a local web page, and the Shrooly app is not in the path. That is a reflash.

The Lykyn plan is the opposite. The stock software stays. We build a translator that sits outside and speaks the same language the cloud already speaks. If Lykyn changes that language, the adapter can break. If it breaks, you still have the official app and can set the box by hand from a grow profile.

Terrashroom is on the flash path, like a Shrooly chamber: community ESPHome firmware, untested on real hardware. AC Infinity is on the outside-control path, like Lykyn: a cloud adapter written from a community integration, also untested on a real controller. Lykyn now has a working stand-in and protocol notes. AC Infinity has adapter code and tests against a fake server.

Can I use a grow profile on a Lykyn today?

Yes. Open the species in the grow profiles, copy the humidity, temperature, fresh air, and light for the stage you are in, and set the official Lykyn app as close as it allows. Or run the stand-in from the lykyn-adapter with an example Black Oyster profile once a TLS or cloud path is in place.

The grow timeline calculator still helps you pick stage dates while the box runs.

Shroom Labs is not made by Lykyn. Product steps quoted above come from the official site and from one stock box on the bench. If you own a box and want to share what the app lets you set, use the contact page on this site and pick A chamber.

FAQ

What does outside control mean?

We talk to the Lykyn through the same Socket.IO protocol its cloud uses, and we leave the stock software on the box.

Will Shroom Labs flash the Lykyn?

No. The plan is outside control. Flashing is how OpenShrooly runs a Shrooly chamber, not how we run a Lykyn.

Can I use a grow profile on a Lykyn today?

Yes, by copying the numbers into the official Lykyn app, or through the public lykyn-adapter stand-in once a TLS or cloud path is in place.

Where is the adapter code?

In the public lykyn-adapter repo on GitHub. It has a Socket.IO stand-in, protocol notes, and Black Oyster example profiles.
