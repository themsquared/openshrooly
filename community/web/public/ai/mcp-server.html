Connect your grow to AI

Ask your AI assistant about mushrooms with the Shroom Labs MCP server

By Mike Moore · Updated 2026-11-21

Shroom Labs runs a free, read only MCP server at https://api.shroomlabs.io/mcp. AI assistants that support the Model Context Protocol can use it to look up culinary grow profiles, stage by stage conditions, grow timelines and our guides, then link the page they used. It needs no account or sign in and cannot touch a chamber.

Connect your grow to AI: flash your Lykyn or Shrooly today

Step 1: put free Shroom Labs firmware on your chamber. Step 2: link it to your free account. Step 3: start Grow Coach, and it reads your chamber's live readings and can adjust it for you.

What can an assistant look up through the MCP server?

Five read only tools: list profiles, get one profile, search grow content, get a chamber guide, and build a grow timeline.

Shroom Labs MCP tools
ToolWhat it returns
list_profilesCulinary grow profiles with slug, species, total days and page URL, with an optional text filter
get_profileOne profile: every stage with days, temperature in °C and °F, humidity, fresh air, light hours, chamber tips and sources
search_grow_contentMatching profiles, guides, blog posts and chamber pages, with title, description and page URL
get_chamber_guideThe chambers hub, Shrooly install, Terrashroom, reuse and FAQ pages
grow_timelineStart and end day for each stage and total days to harvest

How do I connect it to my assistant?

Add https://api.shroomlabs.io/mcp as a remote MCP server using Streamable HTTP with no authentication.

The server answers plain HTTP POST requests and keeps no session, as the MCP specification allows. Where your assistant calls it a custom connector or a remote server, paste the URL and leave authentication off. Test it from a terminal with a tools/list request.

What does an answer look like?

Ask "how long does pearl oyster take" and the assistant can call grow_timeline and get the profile's stage by stage days, 29 in total, with a link to the profile page.

The numbers come from the same profile data as the pearl oyster guide, so the assistant and this site never disagree.

What is not in the MCP server?

No Grow Coach chat, no chamber control, no accounts and no payments: it is a library, not a remote control.

That keeps it safe to leave open to everyone. For advice about a specific chamber, use Grow Coach.
