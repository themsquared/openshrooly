How the pieces fit.

Shroom Labs is a library of researched mushroom grow profiles. Apply them from a Hub to a chamber running OpenShrooly.

Profiles

A Profile is a chamber recipe: humidity, temperature, FAE, light, and days for each stage. Browse culinary Profiles on this site. Pull the profile to your Hub.

Hub

Hub is the local app on your network. It stores Profiles and sends setpoints to a chamber. Growing does not need the cloud.

Grow Coach

Grow Coach is a $3.99 per month culinary subscription. It learns one chamber and suggests safer setpoints. Photo checks and harvest alerts included.

Community

Community is this site: the public catalog, ratings, grow reports, and forks. Works with Shrooly devices running OpenShrooly.

Claim a chamber

Optional. The device shows a 6-character code. Claiming binds it to your account for cloud tools. Local controls still win if the cloud is down.

Install firmware

Flash OpenShrooly over USB from the Install page. Same ESP Web Tools flow as openshrooly.com. After reboot, join OpenShrooly and open the on-device app at 192.168.4.1.
