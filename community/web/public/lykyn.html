For Lykyn owners

Lykyn for mushrooms

Updated 2026-11-15

A Lykyn Smart Mushroom Grow Box is a countertop chamber with humidity, fans, and light. Shroom Labs now runs it with native firmware on the ESP32-C3, validated on a real unit. You get a local web dashboard, an optional cloud link to shroomlabs.io, free grow profiles, and Coach Advisor or Autopilot. Back up the stock image before you flash.

Firmware on GitHubHow to flash a Lykyn

Does Shroom Labs work with Lykyn?

Yes. Native Shroom Labs firmware runs on a real Lykyn, and the chamber is marked supported.

The public firmware is the Shroom Labs Lykyn firmware on GitHub. After it is installed, the box serves a dashboard on your LAN, can link to a Shroom Labs account, loads culinary grow profiles, and can run Grow Coach in Advisor or Autopilot mode. That status is also on the chambers table and the grow log.

What hardware is inside the Lykyn?

An ESP32-C3 runs the box, with an SHT3x temperature and humidity sensor, two PWM fans, an ultrasonic mister, and a 16 pixel grow ring.

Fans are 0 to 100 percent PWM. Humidity targets are 0 to 100 percent relative humidity. There is no heater or cooler; temperature targets are tracked, and over-temperature only boosts the fans. There is no water-level sensor in this firmware. Debug access is ordinary: native USB-Serial/JTAG and download mode for flashing. The pin map is in the firmware repo.

What can I set, and what are the grow stages?

You can set temperature and humidity targets, fan speed and fresh-air timing, mist level, and the light schedule and mix. Stages are Fruiting, Pinning, Colonization, and Custom.

Use Colonization, not Colonizing, on a Lykyn. A Shrooly chamber uses Colonizing for the same stage, and the cloud treats both names as one stage. Colonization lights stay off. Control modes are SMART, MANUAL, and OFF.

How do I install the firmware?

Back up the full stock flash first, then flash the public image from the Lykyn firmware repo. Do not erase the flash.

The stock firmware and this one share a 4 MB partition layout, so you can restore the backup. Erasing flash can wipe factory data that a backup is meant to keep. Build and flash steps are in the flash guide in the firmware repo. After a first boot of the provisioning build, the box opens a Lykyn-Setup Wi-Fi network, and Improv over USB also works. This is not the Shrooly USB installer at /install; that page is for Shrooly chambers.

Read the firmware guide before you start.

How do I connect a Lykyn to Shroom Labs?

Open the local dashboard at the chamber's address, or claim it on shroomlabs.io with the code the box shows.

On your LAN, open http://<chamber-ip>/ for the Shroom Labs dashboard. The stock ESPHome entity table is at /esp. Cloud is optional and outbound: the chamber can enroll at api.shroomlabs.io and show a 6-character claim code and a QR for the claim page. After you claim it, it talks to the site on its own. You can turn the cloud link off in Settings. If the internet is down, the local climate loop keeps running.

Does Grow Coach work on a Lykyn?

Yes. Advisor suggests targets. Autopilot can queue them. Turn Coach off before you set targets yourself.

While Autopilot is on, the site locks climate, fresh air, light, stage, and what's growing. The server rejects those writes until you switch Coach to Advisor. Safety pauses still apply if the chamber looks offline or readings go stale or jump too far. Autopilot uses the same colonization stage on a Lykyn and a Shrooly, with the device-appropriate phase name.

What happened to the outside-control plan?

That was the plan before the unit arrived. The supported path is now native firmware. The older adapter repo is still public as notes.

An earlier page described talking to the official Lykyn app and cloud without flashing. We have not shipped that as the supported path. The Shroom Labs Lykyn adapter on GitHub remains a public place for those notes. If you want to keep the stock Lykyn app instead of flashing, you can still copy numbers from a grow profile into the official app by hand.

Who is working on this?

Shroom Labs. We are not made by or affiliated with Lykyn.

Product facts about the official app and models also come from the Lykyn Smart Mushroom Grow Box. If anything here is wrong, tell us and we will fix it.
