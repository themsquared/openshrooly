For Lykyn owners

Lykyn for mushrooms

Updated 2026-11-05

A Lykyn Smart Mushroom Grow Box is a countertop chamber with an official app. Shroom Labs plans to drive it through that app and cloud, without flashing the box, then document and open-source the adapter. The box is arriving. Outside-control validation has not started, so it is untested on real hardware.

Outside-control guideSee the adapter repo

Does Shroom Labs work with Lykyn?

Not yet. The box is arriving, and outside-control validation has not started, so it is untested on real hardware.

We have a public repo for the adapter pitch and a planned side by side grow with two Shrooly chambers. Until the unit is here and we can read and set it from outside, it runs on its own controls. That status is also on the grow log.

What is a Lykyn Smart Mushroom Grow Box?

It is a countertop mushroom chamber with an official phone app that picks a species and runs humidity, airflow, and light.

Lykyn sells a Single-Tier box and a two layer model. The company says you add water, put in a fruiting block, cut an X, and pick the species in the app (Lykyn Smart Mushroom Grow Box). We have not run one, so those steps are from the official site, not from a Shroom Labs grow.

What does outside control mean?

We talk to the box through the same app and cloud the owner already uses, and we leave the stock software on it.

The adapter, once it exists, would read the same numbers the app shows and write the same kind of settings the app writes. Credentials would stay on your computer. We will not ask anyone to open the box or flash it for this work.

What will Shroom Labs do when the box arrives?

Record what the official app sends to the box and to Lykyn's cloud, write those notes in the public repo, then try a dry run that prints a plan and writes nothing.

The first pass is a watch, not a write. We want to see whether humidity, temperature, fans, and light can be read and set from outside. If that works, we document it and open-source the adapter. If it does not, this page will say so. The empty repo is the Shroom Labs Lykyn adapter on GitHub.

What is untested?

All of it. The box is still in transit, and no adapter code has talked to a real Lykyn.

  • Whether the official app or cloud accepts a sign in from software we write.
  • Whether we can read live humidity and temperature from outside.
  • Whether we can set humidity, fans, light, or a species profile from outside.
  • Whether a grow profile can be applied without using the Lykyn app by hand.
  • How a Lykyn compares to a Shrooly chamber on the same species. That is the planned grow log.

There is no working command line tool yet. Do not treat the repo as something you can run against a box.

How is this different from OpenShrooly on a Shrooly chamber?

OpenShrooly replaces the stock software on a Shrooly chamber by flashing it. The Lykyn plan leaves the stock software on the box and talks to it from outside.

Flashing is how we run a Shrooly chamber, and it is the untested plan for a Terrashroom. Lykyn is the other path: keep the official app, watch how it talks, and build an adapter around that. Read the outside-control guide for the full split.

Can I help?

Yes, if you own a Lykyn. Message us with the model, Single-Tier or two layer, and what the official app lets you set.

Message us and pick A chamber. We are not asking anyone to flash a Lykyn. Notes about what the app shows, and whether it works without the cloud, all help. Every report goes into the adapter notes.

Who is working on this?

Shroom Labs. We are not made by or affiliated with Lykyn.

Product facts on this page come from the Lykyn Smart Mushroom Grow Box. If anything here is wrong, tell us and we will fix it.
