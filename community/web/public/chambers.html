Chambers and controllers

Mushroom chambers that work with Shroom Labs

Updated 2026-10-27

Shrooly is fully supported. Terrashroom has free community firmware that is untested on real hardware. Inkbird and other Tuya Wi-Fi controllers, and AC Infinity controllers, keep their own software: set them from the free grow profiles, or automate them in Home Assistant. Any tub or box works with the profiles too.

Which chambers are supported?

Here is each one and what works today.

Does Shroom Labs work with Shrooly?

Yes. Shrooly is fully supported with free OpenShrooly firmware, grow profiles and the phone dashboard.

OpenShrooly.com, project page by Graham Stewart by Graham Stewart replaces the stock software. You install it from the install page with a USB-C cable. Read reuse your Shrooly first.

Does Shroom Labs work with Terrashroom?

Partly. We have free community firmware for it, but it is untested on real hardware.

It is written from a community pin map and builds cleanly, and we are looking for owners to try it. Read Terrashroom after the shutdown before you open a unit.

Do Inkbird controllers work with Shroom Labs?

They work as they are. Set the controller to the numbers in a grow profile, and Shroom Labs does not control it directly.

If you use Home Assistant, the community tuya-local for Home Assistant integration runs many Tuya based Wi-Fi controllers on your own network. Its list includes the Inkbird ITC306A and ITC308 plug in thermostats. An owner reported in a tuya-local issue that the IHC-200 humidity controller was detected as another device. We have not tested any of these ourselves.

Does AC Infinity work with Shroom Labs?

It works as it is. Set the fan and humidity triggers from a grow profile in its own app, and Shroom Labs does not control it directly.

For Home Assistant, ha-ac-infinity-ble is a community integration for local Bluetooth control of Controller 67 and 69 models. The controller takes one Bluetooth connection at a time, so close the phone app first. Wi-Fi models also work with homeassistant-acinfinity, which signs in to your AC Infinity account. We have not tested either.

What if my chamber is not listed?

Use the free grow profiles. Every one lists the temperature, humidity, fresh air, and light for each stage, so you can set any chamber or tub by hand.

Start with mushroom growing conditions for every species. If your chamber has an ESP32 inside and you want it supported, tell us the model.

What does each status mean?

Supported means we run it ourselves. Community, untested means the firmware exists but has not run on a real unit. Use as is means you keep the stock software.

We only mark a chamber supported once it has run our firmware on real hardware. When that changes for Terrashroom, this page will say so.
