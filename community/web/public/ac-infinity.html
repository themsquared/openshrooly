For AC Infinity owners

AC Infinity for mushrooms

Updated 2026-11-03

An AC Infinity Controller 69 PRO can run a mushroom fruiting chamber: a humidifier, an exhaust fan, and a heater on its ports, each switched by the chamber's humidity and temperature. Shroom Labs has a free community adapter that sets those ports from a grow profile through AC Infinity's cloud. It is untested on real hardware, so we are looking for owners to try it.

Does the Controller 69 PRO work with Shroom Labs?

Yes, as a community, untested controller: our adapter writes grow profile numbers to it over AC Infinity's cloud, and nobody at Shroom Labs has run it on a real controller yet.

The 69 PRO has 4 UIS ports, runs each one at 10 speed levels, and connects to the AC Infinity app over Bluetooth or 2.4 GHz Wi-Fi (AC Infinity Controller 69 PRO manual), and AC Infinity walks through its modes in its Controller 69 PRO overview. The homeassistant-acinfinity integration for Home Assistant lists the Controller 69 WiFi, 69 Pro, 69 Pro+ and AI+ as cloud capable. Our adapter is written from that integration's code, and handles the 69 WiFi, 69 PRO, and 69 PRO+. The AI+ uses a different write call and is not covered yet.

How does a grow tent become a fruiting chamber?

Put a humidifier, an exhaust fan, and a heater on the controller's ports, and let its sensor switch each one on the chamber's humidity and temperature.

  • Humidifier. AUTO mode with the low humidity trigger. The manual says that trigger is for humidifiers: the port turns on when humidity falls to it.
  • Exhaust fan. CYCLE mode for fresh air on a schedule, on for a set time and off for the rest. The manual's high humidity and high temperature triggers are for exhaust fans too, if you would rather vent on those.
  • Heater. AUTO mode with the low temperature trigger, which the manual says is for heating.

AC Infinity lists its CLOUDFORGE humidifiers, CLOUDLINE inline fans, CLOUDRAY clip fans, and THERMOFORGE heaters as working with the 69 PRO (AC Infinity). A martha rack, a shelf unit with a zip cover, works the same way. The build guide has the parts and settings.

Can I plug a regular humidifier or heater into it?

A regular humidifier, yes, through the UIS Control Plug, but use a THERMOFORGE heater for heat.

The AC Infinity turns an outlet device on and off, with no speed control, and only works with devices that start on their own when they get power (AC Infinity). AC Infinity warns against using it for continuous high wattage loads such as heaters. A THERMOFORGE heater plugs straight into a UIS port.

How does the adapter set the controller from a grow profile?

It turns each stage into port settings, signs in to your AC Infinity account, reads each port, and writes the new values back.

  • Humidifier port. AUTO, low humidity trigger at the stage humidity. Speed follows the profile's humidifier speed.
  • Heater port. AUTO, low temperature trigger at the stage temperature minus its hysteresis. Left alone when the stage turns heat off.
  • Fan port. CYCLE, on for the stage fan run and off for the rest of the period. Run times are rounded up to whole minutes, because the integration sets cycle times in minutes.

Your email, password, controller, and ports come from environment variables on your own computer and are never stored by Shroom Labs. It is a dry run by default and prints the plan, and only writes when you add --apply. The code and its tests are in the Shroom Labs AC Infinity adapter on GitHub.

How hard is each way to connect?

The cloud is the easy way for Wi-Fi models, Bluetooth is harder work, and the base Controller 69 only has Bluetooth.

Our adapter uses the cloud. A local Bluetooth version would need no account, and we will add it when the community has the AUTO settings mapped.

What is untested?

All of it, on a real controller. The adapter passes our automated checks against a fake AC Infinity server, but has not written to a real 69 PRO yet.

  • Every write on a real controller.
  • Whether the cloud accepts every value the profiles produce.
  • How fast a CLOUDFORGE humidifier brings a tent to fruiting humidity.
  • The AI+ controller. It is not supported yet.
  • Bluetooth. It is not supported yet.

The cloud API is not published by AC Infinity, so a change on their side could break it. If that happens, set the controller by hand from the grow profiles.

Can I help test it?

Yes. If you own a Controller 69 PRO, message us and we will go through a first dry run and write with you.

Message us and pick A chamber. Tell us your controller model and what is on each port. Every report, good or bad, goes into the adapter notes.
