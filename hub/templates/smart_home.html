Apple Home

  1. Leave this page open so the QR stays on screen.
  2. On the iPhone: Home app, +, Add Accessory, scan the QR.
  3. Tap Add Anyway when it says Uncertified Accessory.
  4. Pick a room. Each chamber should show temperature, humidity, and water (contact: open means add water).

Google Home

Once, on a computer signed into the same Google account the Google Home app uses:

  1. Open the Google Home Developer Console.
  2. Create a project and add a Matter integration with vendor ID 0xFFF1 and product ID 0x8000, named Shroom Labs Hub.

Then on the phone:

  1. If Apple Home already paired this hub, open the bridge in Apple Home, then Turn On Pairing Mode, and use that code in Google Home.
  2. If this is the first pair, Google Home app: Devices, + Add, Matter-enabled device, scan the QR on this page.
  3. Accept the uncertified-device notice and pick a room.

What this step does not do

The grow light cannot be switched from Home yet. The humidifier stays on the chamber's own loop. The bridge talks only to this hub, never to a chamber directly.
